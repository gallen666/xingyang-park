OUTPUT MODES · 对外输出商业模式详解

4 种商业模式 · 从轻到重的复制路径
首年 3700 万营收 · 三年 1.5-3 亿目标

样板一旦形成，输出模式决定杠杆倍率。荥阳设计 4 种模式覆盖不同客户成熟度： 技术授权（最轻 · 起步阶段） · 战略咨询（主打模式） · 联合建设（战略合作） · 合作代运营（最重）。 每种模式配套明确定价、交付节奏与参照对象（Gartner / 麦肯锡 / 华为 / CMMI 认证）。 本页是所有兄弟城市、县级园区、智慧城市规划商的合作入口。

01
Mode 1 · 最轻 · 起步阶段

技术授权（内容 + 商标）

DTSI® / PDTMM® / X-Flow™ / OpenX@X™ 商标授权 · 面向 100+ 城市研究者与咨询公司

02
Mode 2 · 中轻 · 主打模式

战略咨询

国内顶尖研究团队背书 · 荥泽首席咨询 · 麦肯锡级交付节奏

产品：三段式咨询产品，覆盖诊断到规划到复制指导全链路。核心竞争力：清华大学国内顶尖研究团队学术背书（"物感+人感"双感理论首个县级落地）+ 荥泽数链首席咨询团队本地交付。

三段式产品

  • 荥阳智效诊断（3-5 周）—— 基于 DTSI® 完成县级园区数字治理阶段自诊 · 输出 100 页诊断报告 + 7 主体分维度雷达图 + 3 年演化建议路径 + 1 场高管答辩会。定价 ¥50-150 万
  • 双感园区规划（2-3 月）—— 基于诊断结果制定"物感 + 人感"完整规划 · 输出 5 大场景落地路线图 + 4 大平台部署方案 + 3 年 KPI 目标体系。定价 ¥180-500 万
  • 荥阳样板复制指导（6-12 月）—— 全流程陪跑至 PDTMM® 三级认证 · 派驻团队 + 每月复盘 + KPI 达成保障。定价 ¥500-2000 万

目标客户画像

  • 县级园区管委会（尤其是中西部）
  • 地市数据局 / 数字经济产业园主管部门
  • 希望做"体检 + 规划"再决定是否深度共建的政府客户

参照对象

国际一流咨询公司。差异化：行业专家团队学术背书 + 县级样板经验 + 中国本土落地能力。

03
Mode 3 · 中重 · 战略合作

联合建设（荥数链共建）

荥阳分中心 · 技术架构 + 运营 SOP 全部输出 · 6-18 个月交付

产品：荥阳与兄弟城市/园区联合共建"荥阳分中心"—— 技术架构 + 运营 SOP 全部输出，成立合资公司（荥阳占股 20-40%），派驻团队 3 年陪跑。适合有较强财政承担能力、希望"高速起步"的地级市或副地级市。

联合建设核心内容

  • 荥阳智脑 1+1+2+N 架构完整落地（含定制化）
  • 荥感通 · 荥商通 · 荥企通三通产品线本地部署
  • DTSI® / PDTMM® 认证 + X-Flow™ 运行时 + OpenX@X™ 生态
  • 联合运营团队组建（荥阳派驻 + 本地招聘）
  • 3 年 KPI 陪跑 + 年度审计 + 季度复盘

目标客户画像

  • 副地级市 · 地市数据局 · 大县（人口 100 万+）
  • 有较强财政承担能力（初始投资 ¥800 万以上）
  • 希望"高速起步 + 长期陪跑"而非"自己摸索"的政府客户

参照对象

华为智慧城市联合运营 · 阿里云城市大脑联合运营。差异化：荥阳的县级样板更贴近中西部县市实际，投入规模比华为/阿里方案低一个数量级。

Mode 4 · 最重 · 面向全国推广

合作代运营

3 年协议 · 按 KPI 分账 · 缺本地团队的县级园区首选

产品：荥泽数链派驻团队全面接管兄弟园区数字治理，代为运营 3 年，按 KPI 达成分账（渗透性 / 回应度 / 满意度 三段）。适合追求实效但缺乏本地技术团队的县级园区。

代运营核心内容

  • 荥阳派驻 3-8 人团队（含 CDO + 首席架构师 + 数据治理专员 + 接企即办协调员）
  • 4 平台 + 5 大场景全套落地
  • 荥阳智效指数作为 KPI 尺子
  • 3 年 KPI 分账协议（第 1 年保底 + 第 2-3 年阶梯分账）
  • 年度荥阳峰会承办轮值（可争取）

目标客户画像

  • 追求实效但缺乏本地技术团队的县级园区
  • 希望"荥阳全面负责、我只看结果"的政府客户
  • 愿意接受 KPI 分账模式（而非固定咨询费）的合作方

参照对象

CMMI 认证 + 埃森哲 BPO（业务流程外包）混合模式。差异化：以数字治理成效（智能-智治-智效）作为分账依据，而非以工时或人日数。
